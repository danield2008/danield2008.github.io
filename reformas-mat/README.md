# Reformas Mat

Landing page estática para reformas de baños y cocinas en Castellón y alrededores.

## Antes de captar clientes

1. En `index.html`, busca `const WHATSAPP_NUMBER='34600000000';` y cámbialo por el WhatsApp real, con prefijo de país y solo dígitos (por ejemplo, España: `34600111222`).
2. Reemplaza las imágenes de inspiración por fotos de trabajos reales cuando las tengas; no las presentes como proyectos propios.
3. Añade teléfono, correo, aviso legal y política de privacidad reales antes de una publicación comercial.
4. El formulario abre WhatsApp con el mensaje preparado; la persona debe confirmar el envío en WhatsApp.

## GitHub Pages

Esta carpeta está dentro del repositorio personal `danield2008.github.io`. Si GitHub Pages está activo para la rama `main`, la página debería estar disponible en:

https://danield2008.github.io/reformas-mat/

Si no aparece, revisa en Settings → Pages que la fuente esté configurada en `main` y la carpeta `/ (root)` del repositorio. Los cambios pueden tardar unos minutos en publicarse.
